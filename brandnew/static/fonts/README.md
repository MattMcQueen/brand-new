## Figtree and Young Serif

The same fonts as the Matt Rarely Writes blog, so the two sites look alike: Figtree for text and
Young Serif for the logo and headings. These are the files Google Fonts serves (through Next's
`next/font/google` on the blog), split into Latin and Latin Extended by `unicode-range`:

- `figtree-latin.woff2`, `figtree-latin-ext.woff2`: Figtree, variable weight 300–900.
  Copyright 2022 The Figtree Project Authors (https://github.com/erikdkennedy/figtree). [OFL-figtree.txt](OFL-figtree.txt)
- `young-serif-latin.woff2`, `young-serif-latin-ext.woff2`: Young Serif, weight 400.
  Copyright 2023 The Young Serif Project Authors (https://github.com/noirblancrouge/YoungSerif). [OFL-young-serif.txt](OFL-young-serif.txt)

## DM Sans

`dm-sans-600-latin.woff2`: DM Sans, weight 600, Latin subset, as served by Google Fonts
(fonts.gstatic.com, v17). Used only for the "Support me" button, to match Ko-fi's own button.
Copyright 2014 The DM Sans Project Authors (https://github.com/googlefonts/dm-fonts). [OFL-dm-sans.txt](OFL-dm-sans.txt)
